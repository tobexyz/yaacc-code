# Privacy Policy - Hosting via GitHub Pages

Our website utilizes the "GitHub Pages" service for hosting and displaying content. This service is provided by **GitHub, Inc.** (88 Colin P. Kelly Jr. St., San Francisco, CA 94107, USA) or, if you are resident in the EU, by **GitHub Technologie BV** (Prins Bernhardplein 200, 1097 JB Amsterdam, Netherlands).

When you visit this project website, your browser automatically establishes a connection to GitHub's servers. During this process, technical data—specifically your **IP address**, timestamp of the visit, and details about your browser configuration—is processed and stored in temporary server log files.

* **Legal Basis:** The processing of this data is based on our legitimate interest (Art. 6 para. 1 lit. f GDPR) in providing a secure, stable, and functional presentation of our software project.
* **Data Transfer:** GitHub processes data globally. To ensure an adequate level of data protection for transfers to the USA, GitHub utilizes Standard Contractual Clauses (SCCs) approved by the European Commission, as well as the EU-U.S. Data Privacy Framework.

For more details on how GitHub handles user data, please refer to the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).
